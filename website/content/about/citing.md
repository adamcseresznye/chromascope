# Citing Chromascope

If Chromascope helped with work you publish, please cite the program and say which version you used. The version is under **File**, then **About Chromascope…**.

## Suggested citation

> Cseresznye A. Chromascope: an open-source, AI-ready LC-MS workbench (version 0.3.0) [software]. https://github.com/chromascope-ms/chromascope

Replace the version with the one you used. A permanent identifier (a DOI) has not been issued yet.

## For methods sections

State the version, the integration algorithm and baseline you chose, the smoothing, the calibration model and weighting, and whether peaks were reviewed by a person. The audit package (see [Audit package and projects](../manual/audit-package.md)) records all of these next to the numbers, so you can quote it.
